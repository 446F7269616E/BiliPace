# BiliPace 手工验收

## 测试准备

为每个候选版本记录 commit SHA、版本号、构建命令、浏览器/操作系统版本和产物 SHA-256。使用新的浏览器 profile，另准备一个含上版本数据的升级 profile。测试账号不应包含敏感私人数据。

至少准备以下时钟情形：普通工作日、23:58 跨午夜、跨周/月末、当地 DST 切换（可用受控 clock/unit test 补足）和系统休眠恢复。

## 核心验收

### 安装与引导

- [ ] 全新安装只显示与当前功能相符的权限说明；没有 `<all_urls>` 或站外访问警告。
- [ ] 首次引导说明“非官方”、本地数据、开始/暂停方式、计划与临时放行。
- [ ] 工具栏弹窗直接显示“计划模式”开关和“管理观看清单”入口；无需先进入详细设置即可开启。
- [ ] 跳过引导不影响后续从设置重新查看；键盘可完成整个流程。
- [ ] popup、home、options、dashboard、plan 均可打开，无控制台错误、空白页、闪退或无限加载；在普通标签页打开扩展页也能收到 background 响应。
- [ ] 专注中心、观看清单、使用洞察、专注设置显示相同顺序的全局导航；当前页有明确状态，品牌、面包屑和“返回专注中心”均无死路且不重复打开新标签。

### 屏蔽与导航

- [ ] 分别打开主页、动态、视频播放页及一个未知 Bilibili 路由，逐项切换屏蔽后结果只影响目标板块。
- [ ] 在同一标签页通过站内链接 SPA 导航，URL/板块变化后 1 秒内应用新规则。
- [ ] 刷新、前进、后退、复制链接新开标签、多个 Bilibili 标签同时打开，不产生重复遮罩或失效样式。
- [ ] 遮罩包含原因、当前计划/剩余时间、临时放行和关闭/管理入口；不能形成无法退出的页面陷阱。
- [ ] Bilibili DOM 小范围异常或关键选择器缺失时安全降级，不误删用户内容、不阻塞登录/安全验证。
- [ ] 分别切换首页推荐、动态流、相关视频、评论、搜索联想、推广和顶部导航；只隐藏所选内容，整页专注开关不被混淆。
- [ ] 开启关键词与安全正则过滤后，原生信息流和搜索结果中的命中卡片即时隐藏；新增卡片可增量处理，输入不安全规则不冻结页面。
- [ ] `/` 在非输入状态下聚焦站内搜索；输入框、编辑器、组合输入和带修饰键时不抢占按键。
- [ ] 安装 BewlyBewly! Ave Mujica，在 `?page=Home/Search/Anime/Moments` 之间切换；实时计时、整页专注与计划模式继续可用，未知 `?page=` 不误算为首页。
- [ ] Ave Mujica 中的搜索联想、标题规则和 `/` 搜索快捷键可用；重建 `#bewly[data-version]`/ShadowRoot 后自动恢复，选择器失效时安全放行。
- [ ] Ave Mujica 的 iframe 不产生第二个计时会话或重复计划跳转；原生视频页的评论和相关推荐仍由原生适配层处理。

### 计划与临时放行

- [ ] 创建、编辑、禁用、删除单日/多日计划，刷新和重启浏览器后仍正确。
- [ ] 验证开始时刻、结束前一秒、结束时刻；无 off-by-one。
- [ ] 验证跨午夜、跨周/月、重叠计划与本地时区变化。
- [ ] 临时放行只作用于选择的板块和时长；过期、重启、系统休眠后不会延长。
- [ ] 修改系统时间不会产生负统计或绕过无限放行；恢复时间后状态可自愈。

### 观看计划模式

- [ ] 默认关闭；开启后从首页、动态、直播、搜索、个人空间及未知 Bilibili 子域打开链接，都会先进入 `plan.html`，且计划页地址不包含来源 URL/查询参数。
- [ ] 手动添加有效视频链接或 BV 号；无效 host、HTTP、短链、错误 BV、超长标题和重复视频给出明确反馈且不写入队列。
- [ ] 编辑、删除、完成、恢复、上移、下移在刷新/重启后保持一致；键盘可完成全部操作，首尾项的无效移动不可用。
- [ ] 批量粘贴每行链接或“标题 | 链接”，检查去重、无效项计数、勾选导入和规模上限；Network 中不产生补全标题或解析短链请求。
- [ ] 点击清单项“开始观看”后，只放行该精确 BVID；刷新可继续，打开相关视频/其他 BV/首页/其他子域立即回到计划页。
- [ ] 授权到期，或将条目完成、删除、修改 BV，或暂停后重新开启计划模式，旧授权失效。
- [ ] “稍后再看/收藏夹”按钮明确显示官方接入待配置且不可用；产品不要求密码、不读取 Cookie、不声称已登录。
- [ ] 计划模式拦截期间不累计使用时间；开始观看的已授权视频按普通计时与板块规则处理。

### 计时与仪表盘

- [ ] 前台聚焦观看约 2 分钟，统计误差在产品定义容差内（建议不超过一个心跳周期）。
- [ ] 切换到其他标签、最小化窗口、页面隐藏/冻结、锁屏/休眠时停止累计。
- [ ] 两个可见窗口同时打开 Bilibili 时，产品对“多窗口”的口径与 UI 文案一致，不能静默双倍计时。
- [ ] SPA 从主页切到视频后，时间正确拆分到不同板块。
- [ ] 日/周/月范围总计与分项之和一致；无数据、单板块、超长名称与大数值布局正常。
- [ ] 跨午夜会话拆到两个日期；周起始日和本地化规则一致。
- [ ] 清空数据二次确认后立即归零，刷新、重启及其他打开的 dashboard 不再显示旧数据。
- [ ] popup、专注中心和使用洞察实时显示“正在计时 · 板块”或暂停原因；读取使用时间前结算当前片段，数值不会长期滞后。

### 可访问性与视觉

- [ ] 只用键盘完成开关、计划编辑、范围切换、临时放行和清空数据；焦点顺序与焦点环清楚。
- [ ] 开关有名称与当前状态；表单错误和图表信息可被读屏软件理解。
- [ ] 200% 缩放、窄 popup、系统深浅色、减少动态效果、高对比度下没有功能丢失。
- [ ] 色彩不是状态的唯一表达；中文文本无截断，时间/数字使用一致格式。
- [ ] 主界面不出现 provider、schema、服务端配置、维护者资质等内部词；错误给出用户结果和重试动作，不显示原始异常。

### 数据与网络

- [ ] DevTools Application/Storage 中只存在已声明 schema；统计无完整 URL/标题，观看计划只有主动添加的 canonical URL、BV 号、标题、顺序和完成状态，无账号、Cookie 或页面正文。
- [ ] 运行 15 分钟并操作所有功能，Network/抓包中无开发者或第三方遥测、广告、分析请求。
- [ ] 导出/错误信息（若有）不含浏览历史、密钥、内部堆栈或个人页面内容。
- [ ] 卸载后浏览器移除扩展数据；重新安装按全新状态启动。

## 平台专项

### Chromium / Chrome Web Store 候选

- [ ] 从 `dist/chromium` 加载，Service Worker 可被回收后再次唤醒，计划/统计仍正确。
- [ ] 在扩展详情中把 Bilibili 站点访问改为拒绝，再恢复；UI 给出可操作提示。
- [ ] 从上一商店版本升级，schema 迁移幂等且统计不丢失。

### Firefox / AMO 候选

- [ ] `web-ext lint --source-dir dist/firefox` 无 error；warning 均有记录。
- [ ] 使用 `web-ext run --source-dir dist/firefox` 执行全部核心验收。
- [ ] 验证稳定 `gecko.id`、准确 `data_collection_permissions`、Firefox Promise/回调差异和非持久 background event page 生命周期。
- [ ] 用 AMO 签名候选 XPI 做安装、升级、禁用/启用与卸载。

### Safari macOS

- [ ] `xcrun safari-web-extension-packager dist/safari` 的所有 manifest 警告均已处置并存档。
- [ ] 临时加载扩展或从 Xcode Debug 安装；重启 Safari 后按该安装方式预期工作。
- [ ] 对 Bilibili 网站权限逐一测试拒绝、允许一天、始终允许、撤销；拒绝时 UI 不声称正在计时/屏蔽。
- [ ] 确认不调用 `storage.sync`，验证 Safari 本地存储容量边界和 Safari 更新由承载 app 分发处理。
- [ ] 用 VoiceOver 完成核心流程；Private Browsing 默认不假定获准。

### Safari iOS/iPadOS

- [ ] 从 Xcode/ TestFlight 安装承载 app，用户能发现、启用扩展并授予最小网站权限。
- [ ] 至少一台受支持真机完成主页、动态、视频、计划、临时放行、dashboard 和清空数据。
- [ ] 后台/锁屏/内存回收、横竖屏、分屏和动态字体不会虚增时长或破坏操作。
- [ ] 承载 app、扩展名、隐私信息、图标和“非官方”说明一致。

## 通过标准

P0/P1 缺陷为零；权限、隐私、数据丢失、无法退出屏蔽、错误计时、签名/升级失败均视为 P0/P1。每个平台的清单须由非实现者复核，并把证据链接到 release 记录。
