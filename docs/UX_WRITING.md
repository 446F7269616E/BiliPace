# Hourleaf 界面文案规范

> 状态：发布门禁

文案只说明当前状态、必要原因和可执行动作。保持短、自然、具体，不承担教程、劝导或内部技术说明。

## 规则

1. 标题使用用户目标：“仪表盘”“计划”“配置”“设置”。
2. 控件使用直接动作：“添加网站”“保存”“开始”“临时访问”“删除”。
3. 不使用口号、反问、鼓励、拟人或内疚表达。
4. 不使用“第一步、下一步、首次使用”等教程结构；删除引导卡片。
5. 错误只写结果与恢复动作，不展示异常栈、schema、provider、模块协议或维护建议。
6. 权限文案明确对象和范围，例如“允许 Hourleaf 在 example.com 计时和执行规则”。
7. 模块状态统一为“启用 / 停用 / 删除 / 恢复”，不使用“获取”或“下载”。
8. 隐私文案使用可核验事实，不写“绝对安全”“安心守护”。
9. 状态不只靠颜色；可见文字、`aria-label` 和控件状态一致。
10. 删除、清空和恢复设置明确对象并二次确认。

## 统一术语

| 含义               | 使用       |
| ------------------ | ---------- |
| 用户授权的来源     | 网站       |
| 网站内独立规则范围 | 目标       |
| 隐藏推荐、评论等   | 内容降噪   |
| 指定时间允许访问   | 可用时段   |
| 指定时间限制访问   | 不可用时段 |
| 短时绕过规则       | 临时访问   |
| 可选站点能力       | 站点模块   |

加载、成功、错误和空状态优先使用“正在加载”“已保存”“加载失败 / 重试”“暂无记录”。评审时检查四页名称一致、无导航死路、窄屏/200% 缩放不截断、读屏可理解，并与 `PRIVACY.md` 及实际权限一致。
