# BiliPace 界面文案规范

> 状态：发布门禁（normative）  
> 适用范围：扩展页面、站内提示、错误、空状态、权限说明、README 与商店文案

## 基本原则

界面只写当前状态、必要原因和可执行动作。文案保持简短、中性、具体，不承担教学、劝导或情绪安慰。

## 必须遵守

1. 标题使用功能或状态名称，例如“仪表盘”“计划”“当前页面已受限”。
2. 控件使用直接动作，例如“保存”“开始观看”“临时访问”“删除”。
3. 不使用口号、反问、鼓励或拟人表达；避免“真正想看”“从此刻开始”“温和调整”“为你准备”等句式。
4. 不使用“第一步、下一步、第一次使用”等教程结构。必要操作由布局、标签和控件本身表达。
5. 加载、错误和空状态只写事实；错误保留重试入口，不显示异常栈或内部代码。
6. 不责备、不制造内疚，不使用“浪费、戒断、沉迷”等评价性表达。
7. 隐私说明使用可核验事实，不使用“安心、安全守护”等宣传词。
8. 不展示 provider、schema、应用密钥、服务端配置或开发路线图。
9. 状态不只靠颜色；可见文字、`aria-label` 和视觉状态必须一致。
10. 删除或不可逆操作明确对象，并要求二次确认。

## 统一术语

| 含义                     | 使用       | 不使用              |
| ------------------------ | ---------- | ------------------- |
| 隐藏推荐、评论等页面内容 | 内容降噪   | DOM 过滤 / 清理页面 |
| 到时限制整个板块         | 专注拦截   | 强制戒断            |
| 指定时间内始终允许访问   | 可用时段   | 白名单策略          |
| 指定时间内始终限制访问   | 不可用时段 | 黑名单策略          |
| 短时间绕过规则           | 临时访问   | 临时放行            |
| 待看的视频               | 计划       | 队列 / 计划项       |

## 状态模板

- 加载：`正在加载`
- 成功：`已保存` / `已添加`
- 错误：`加载失败` / `保存失败` + `重试`
- 空状态：`暂无计划` / `暂无使用记录`

## 评审清单

- [ ] 首屏只保留当前页面名称、状态、数据和操作。
- [ ] 四个页面名称与左侧菜单一致。
- [ ] 没有教程卡片、步骤说明、口号或情绪化建议。
- [ ] 没有原始异常、内部模块名或开发配置。
- [ ] 文案在窄屏、200% 缩放和读屏语义中完整。
- [ ] 不可逆操作有明确对象和二次确认。
- [ ] 隐私陈述与 `PRIVACY.md`、权限和实际网络行为一致。
